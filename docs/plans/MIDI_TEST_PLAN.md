# План быстрой проверки MIDI-подключения

Разрабатываемое приложение будет представлять собой тренажер и проверку игры на пианино, подключенное через usb к устройству, на котором установлено это приложение. 

Этот план описывает шаги для быстрой проверки подключения MIDI-пианино к приложению и получения от него сообщений.

## 1. Добавить разрешение в `AndroidManifest.xml`

Чтобы приложение могло работать с MIDI-устройствами, необходимо запросить соответствующее разрешение.

Откройте `app/src/main/AndroidManifest.xml` и добавьте следующую строку внутри тега `<manifest>`:

```xml
<uses-permission android:name="android.permission.MIDI" />
```

## 2. Обнаружить и подключиться к MIDI-устройству

В коде вашего `Fragment` или `Activity` нужно найти подключенное MIDI-устройство и открыть его.

- Получите системный сервис `MidiManager`.
- Запросите у него список подключенных устройств.
- Откройте первое найденное устройство для получения данных.

## 3. Создать `MidiReceiver` для приема сообщений

Это класс, который будет "слушать" входящие MIDI-команды от пианино.

- Создайте новый класс, унаследованный от `android.media.midi.MidiReceiver`.
- Переопределите в нем метод `onSend()`. Этот метод будет срабатывать каждый раз, когда от устройства приходит MIDI-сообщение (например, при нажатии или отпускании клавиши).

## 4. Показать обратную связь

Чтобы убедиться, что сигнал дошел, достаточно вывести простое уведомление.

- Внутри метода `onSend()` вашего `MidiReceiver`-а покажите `Toast` с текстом "MIDI-сообщение получено!".

## 5. Запустить и проверить

- Подключите электронное пианино к вашему Android-устройству (через USB-OTG адаптер).
- Запустите приложение.
- Нажмите любую клавишу на пианино.
- Если на экране появился Toast с вашим сообщением, значит, подключение успешно установлено и данные поступают.
