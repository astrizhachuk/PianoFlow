# Use Case для уведомлений о подключении

## Цель документа

Данный документ описывает формальный Use Case (сценарий использования) для функционала отображения уведомлений о состоянии подключения MIDI-клавиатуры. Документ является частью общего описания [подключения USB MIDI-клавиатуры](./USB_MIDI_KEYBOARD.md) и предназначен для:

- Формального описания функциональных требований к уведомлениям
- Планирования приемки функционала уведомлений
- Тестирования функциональности уведомлений

## Общее описание функционала

Данный use case является частью более общего функционала [отслеживания подключения MIDI-клавиатуры](./USB_MIDI_KEYBOARD.md).
Система обрабатывает различные состояния подключения (успешное подключение, отключение, ошибки) и информирует пользователя через уведомления.

---

## UC-002: Отображение уведомлений о состоянии подключения

### Идентификатор
UC-002

### Название
Отображение уведомлений о состоянии подключения

### Краткое описание
Система обрабатывает различные состояния подключения MIDI-клавиатуры (успешное подключение, отключение, ошибки) и преобразует их в понятные сообщения для пользователя, отображаемые через уведомления.

### Актор
Система (автоматическая обработка)

### Предусловия
1. Произошло изменение состояния подключения MIDI-устройства (подключение, отключение, ошибка)
2. Система вызвала обработчик уведомлений

### Постусловия
1. Состояние классифицировано и преобразовано в понятное сообщение
2. Пользователь информирован о состоянии через уведомление

### Основной поток

1. Система получает информацию о состоянии подключения (успешное подключение, отключение, ошибка)
2. Система анализирует тип состояния
3. Система определяет категорию состояния согласно таблице соответствия
4. Система формирует понятное сообщение для пользователя на русском языке (todo потом локализовать для других языков)
5. Система отображает уведомление с соответствующим сообщением

### Таблица соответствия состояний и сообщений

| Тип состояния / Ситуация             | Сообщение для пользователя                                    |
| ------------------------------------ | ------------------------------------------------------------- |
| Успешное подключение                 | "MIDI-клавиатура подключена"                                  |
| Успешное отключение                  | "MIDI-клавиатура отключена"                                   |
| Устройство недоступно                | "Устройство недоступно. Проверьте подключение."               |
| Нет разрешения на доступ к MIDI      | "Нет разрешения на доступ к MIDI-устройству."                 |
| Ошибка соединения с устройством      | "Ошибка подключения к устройству. Попробуйте переподключить." |
| Устройство занято другим приложением | "Устройство уже используется другим приложением."             |
| MIDI не поддерживается на устройстве | "MIDI не поддерживается на данном устройстве."                |
| Неизвестная ошибка                   | "Произошла ошибка при подключении к устройству."              |

### Критерии приемки

1. ✅ Все типы состояний (успешные и ошибки) преобразуются в понятные сообщения для пользователя
2. ✅ Сообщения отображаются на русском языке (todo потом локализовать для других языков)
3. ✅ Каждый тип состояния имеет соответствующее сообщение из таблицы соответствия
4. ✅ Неизвестные ошибки обрабатываются с общим сообщением
5. ✅ Все сообщения отображаются через уведомления
6. ✅ Сообщения помогают пользователю понять текущее состояние подключения или причину ошибки
